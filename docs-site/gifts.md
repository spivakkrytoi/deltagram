# Подарки в клиентах

- Каталог: `payments.getStarGifts`.
- Замок: `locked_until_date` (Unix-время). До открытия кнопка покупки
  блокируется, Android показывает красный замок.
- Кастомная верификация в Android — 17dp, не перекрывает никнейм.
- Клик по «пузырькам» NFT-подарков открывает внутреннюю карточку
  `StarGiftSheet`, а не внешний `t.me/nft`.
- Обводки аватара fire/blue/green рисуются одним ободком **под** аватаром;
  лишние заливки и второй ободок убраны.
- Баннер профиля загружается через Deltament (`POST /api/cards/banner`) и
  подписывается MTProto-ключом (`DeltaGram <auth_key_id>:...`).

## Коллекционные подарки

У подарка может быть опубликованный пул моделей, паттернов и фонов. Клиент
получает их в карточке коллекционного подарка. Для показа превью Gift Lab
использует те же Lottie-анимации, что и клиент.

## Выдача

Обычная покупка требует `enabled=true`. Операторская выдача через admin API
может использовать `allow_disabled=true` для снятых с продажи подарков, если
у коллекции остался свободный тираж.

::: warning Тираж
Полностью исчерпанный тираж коллекции не выдаётся: это защищает нумерацию
уникальных подарков. Снятый с продажи подарок с остатком выдать можно.
:::
