# Админ-панель

Вход: `http://150.241.69.39:2600/accounts`. Логин `admin`, пароль —
`TELESRV_ADMIN_UI_PASSWORD` из `/opt/gramsrv/deploy/docker/.env`.

Разделы:

- **Аккаунты** — поиск, профиль, сессии, баланс, блокировки.
- **Подарки** — каталог, ревизии, коллекции, лимиты, расписание, выдача.
- **Каналы / боты / юзернеймы / номера** — соответствующие реестры.
- **Аудит** — журнал административных команд.

## Лимиты подарков

В форме **«Импорт набора подарков»** и в форме одного подарка доступны:

- **Лимит подарков** — общий тираж (`availability_total`), `0` — без лимита.
- **Лимит на пользователя** — `per_user_total`, `0` — без ограничения.
- **Цена**, **конвертация**, **сортировка**.

Для гифтпака значения применяются к подаркам, у которых в `pack.json` нет
собственных `limited` / `availability_total` / `per_user_total`. Значения из
`pack.json` имеют приоритет.

## Расписание продаж

- **Одноразово** — дата и время по Киеву; после этого подарок доступен всегда.
- **Ежедневное окно** — время открытия по Киеву и длительность 1–1440 минут.

Время хранится как абсолютный Unix timestamp. Клиент показывает его в часовом
поясе пользователя (21:40 Киев = 22:40 Москва). До открытия клиент рисует
красный замок, сервер отклоняет покупку.

## Sold out и resale

- Sold out-подарки скрываются через `star_gift_catalog.enabled = false`.
- Resale-предложения лежат в `star_gift_listings`; приостановленные листинги
  имеют `suspended = true`.
- Счётчики `availability_resale` / `resell_min_stars` пересчитываются по
  активным листингам.
- Резервная копия перед чисткой магазина: `star_gift_cleanup_20261127`.

## Коллекции подарков

Коллекционный пул состоит из:

- моделей — `star_gift_collectible_models`;
- паттернов — `star_gift_collectible_patterns`;
- фонов — `star_gift_collectible_backdrops`.

Публикация: `POST /v1/gifts/{id}/collectibles/publish`.

Служебные маршруты admin API (bearer-токен):

- `GET /v1/gifts` — весь каталог, включая снятые с продажи; поле `enabled`
  показывает, виден ли подарок в магазине.
- `GET /v1/gifts/{id}/collectibles` — пул фонов, моделей и символов.
- `GET /v1/gifts/{id}/collectibles/{kind}/{attribute_id}/animation` —
  Lottie-анимация атрибута.
- `POST /v1/gifts/give` — выдача. Для снятого с продажи, но опубликованного
  подарка передайте `upgrade=true` и `allow_disabled=true`.
